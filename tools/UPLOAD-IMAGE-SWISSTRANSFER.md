# Uploading the KalynaOS image with SwissTransfer

SwissTransfer is a manual browser-based file-transfer service. It does not provide a public upload API, and its current upload flow uses browser-side reCAPTCHA. Do not try to upload from GitHub Actions or automate/bypass the CAPTCHA.

## Get the image

1. Open the successful image-build run:
   https://github.com/whatmode/KalynaDroid/actions/runs/43490093607
2. Download the artifact named `kalynaos-cachyos-handheld-steamdeck-microsd`.
3. Extract the downloaded artifact ZIP.
4. Locate `KalynaOS-CachyOS-Handheld-SteamDeck.img.xz` (about 6.4 GiB in this build).

## Upload

1. Open https://www.swisstransfer.com/.
2. Add the extracted `.img.xz` file. The free service accepts up to 50 GB per transfer.
3. Choose a 30-day availability period and a suitable download limit.
4. Choose link sharing, complete the upload, and copy the generated link.
5. Test the link in a private/incognito window before sharing it.

SwissTransfer is temporary hosting, not permanent release storage. The transfer expires, so keep the verified GitHub Actions artifact as the source copy.

## Verify the download

After downloading the file from SwissTransfer, compare its SHA-256 checksum with the checksum generated by the image-build workflow before flashing it. Never flash an image whose checksum does not match.
